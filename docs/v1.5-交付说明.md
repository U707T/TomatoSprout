## Room v1 → v2 Migration

`AppDatabase.MIGRATION_1_2`（无 DROP TABLE）：

1. `tasks` 增加 `sortOrder INTEGER NOT NULL DEFAULT 0`
2. `tasks` 增加 `timerMode TEXT`、`focusMinutes INTEGER`（可空，读取时回退 countdown / 25）
3. 新建 `subtasks`：`id`、`parentTaskId`、`title`、`done`、`sortOrder`、`createdAt`，外键 `ON DELETE CASCADE`，`parentTaskId` 索引
4. 旧 `tasks.parentId` 子任务写入 `subtasks`（保留旧行，避免破坏历史打卡引用）
5. `focus_sessions` 增加 `note TEXT`（心得）
6. 同步/备份 schemaVersion 升至 2；v1 文件仍可导入，缺少的子任务列表按空处理

迁移 SQL 已用 SQLite 逐步执行验证（见开发记录）；Room schema v2 已导出到 `app/schemas/`。

## 权限

仅 4 个：`POST_NOTIFICATIONS`、`INTERNET`、`ACCESS_NETWORK_STATE`、`RECEIVE_BOOT_COMPLETED`。
WorkManager 传递引入的 `WAKE_LOCK` / `FOREGROUND_SERVICE` 仍通过 Manifest 移除规则剔除。

## 红线复查

- 全项目 UI 无「学霸模式 / 白名单 / 锁机」入口、图标或文案
- 未申请悬浮窗 / 无障碍 / UsageStats / 通知推广权限
- 快捷面板仅保留用户要求的按钮，没有额外模式入口
- 未引入任何托管后端 SDK

## 已知取舍

- 计时兜底使用 `setAndAllowWhileIdle`，无精确闹钟权限，系统可能延迟
- 正向计时 <30s 的确认只在 `ignoreShortFocus` 开启时出现（默认开启），确认框默认不记录
- 时间轴按专注结束日归属；午夜归属仍写入 `isMidnightShifted` 供统计说明
- 图表自定义范围使用两个系统 DatePicker（开始/结束），不做第三方日历依赖
