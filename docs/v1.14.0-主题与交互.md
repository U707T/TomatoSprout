# v1.14.0 主题色与首页操作流

这轮改的是两件互相支撑的事：**外观第一次可以选**，**首页的重操作第一次可以少点两下**。
没有换设计语言 —— 暖白纸感、1dp 描边、8pt 栅格全部沿用 v1.9 的那套，只补两块：

1. 强调色从写死一个番茄红，变成六套可选、且对比度可验证；
2. 首页从「长按 → 面板 → 再点」的单一路径，补上排序和滑动两条更短的路径。

---

## 1. 为什么只换强调色

参考 cfbrowser 的「墨笺」：纸（paper）与墨（ink）固定，强调色只落在少量高信息量的位置。
理由不是审美偏好，而是**换色成本**：

| 方案 | 影响面 | 风险 |
|---|---|---|
| 整屏换色（纸面也染色） | 每个 `surface` / `background` / 描边 / 图表 | 31 处底色、暗色对比度全部要重算，容易一边好看一边读不清 |
| 只换 primary 一组（本次） | 按钮、链接、进度条、选中态、图表主色 | 纸面与墨色不动，暗色模式只需验 3 对比 |

实现上，`MaterialTheme.colorScheme` 仍是 v1.9 那份纸面配色，`TomatoTheme` 在最后一步
用 `ColorScheme.copy()` 覆盖 `primary / onPrimary / primaryContainer / onPrimaryContainer / inversePrimary`。
所以**所有已经在用 `colorScheme.primary` 的页面自动获得主题色**，没有逐页改。

## 2. 六套主题色与对比度

浅色档（背景是纸面 `#FAF6F1`）：

| 主题色 | primary | 白字对比 | 纸面对比 |
|---|---|---|---|
| 番茄（默认） | `#BE4834` | 5.04 | 4.68 |
| 黛青 | `#2C5A78` | 7.39 | 6.87 |
| 松烟 | `#3B6A4E` | 6.25 | 5.81 |
| 赭石 | `#875B22` | 5.92 | 5.50 |
| 梅子 | `#8A3B5C` | 7.34 | 6.82 |
| 墨色 | `#3B332D` | 12.37 | 11.50 |

> 默认番茄红从 `#E0553F` 换成 `#BE4834`：原来的白字只有 **3.79:1**，
> 14sp 的按钮文字其实不合格（大字才勉强）。新值 5.04:1，色相没变，只是压深一档。
> 品牌色 `#E0553F` 仍保留在 `Palette.Tomato`，继续用于插画与图标，不承载正文。

深色档（背景 `#14110F`）：六套的 primary 都在 8.1–12.1 之间，`onPrimary` 用深墨，不刺眼。

这些不是人工目测，`AccentContrastTest` 对 18 组配对逐一断言 ≥ 4.5:1。
以后谁改色值，先跑测试。

## 3. 首页操作流

### 3.1 排序

- 入口：首页右上「排序与视图」（列表图标）。
- 四种：手动 / 优先级（四象限）/ 截止时间 / 今日专注。
- **只改展示顺序，不写 `sortOrder`**：切回手动，还是你上移下移调好的位置。
- 选择存 DataStore（`task_sort`），重启、次日都在；属于本机偏好，不参与 WebDAV 同步。
- 同一张弹层里放了「简约卡片」开关，不用再绕去设置页。

排序逻辑抽成纯函数 `sortCards(cards, mode)`，`TaskSortTest` 锁住：
手动保序、已完成永远沉底、没设截止的排最后、今日专注按分钟再按次数。

### 3.2 滑动

| 方向 | 动作 | 适用范围 |
|---|---|---|
| 右滑 | 打卡 / 完成 / 重新打开 | 按次任务与已完成任务；**计时任务禁用**，避免滑动误启动专注 |
| 左滑 | 删除（10 秒可撤销） | 全部任务 |

实现要点：

- `confirmValueChange` 一律返回 `false`：动作在回调里触发，卡片自己弹回，不留在滑走状态。
- 露出层只用 `primaryContainer` / `errorContainer`，不引入第三种彩色。
- 触感：打卡走 `confirm()`，删除走 `reject()`。

### 3.3 删除与撤销

滑动删除不是立刻写库，而是：

```
左滑 → 卡片隐藏 + 底部提示条「已删除「x」 撤销」（10 秒）
      ├─ 点撤销 → 取消任务，卡片回来
      └─ 超时 / 被新提示顶掉 → 真正软删除（历史仍保留）
```

这样不需要「从墓碑恢复」那套机制，也不会出现「先弹已删除、撤销窗口还开着」的双重提示。
连滑两张时，前一张的删除会立即落地，不会互相覆盖。

顺带修了两处旧问题：

- 撤销条从 `SnackbarDuration.Short`（4 秒）改成 `Long`（10 秒）—— 4 秒基本来不及点。
- 撤销打卡后的按钮文案从「撤销」改成「恢复」：再点一次是把打卡加回来，不是再撤一次。

### 3.4 快捷提醒

以前长按 → 提醒，会跳到整页编辑表单 —— 和「编辑」是同一个目的地，等于多绕一层。
现在改成弹层内直接完成：

- 五个常用时间（08:00 / 12:00 / 18:00 / 20:00 / 22:00）点一下就生效；
- 「自定义时间」调系统时间选择器；
- 已有提醒时多一个「关闭提醒」。

写库仍走 `saveForTask`（复用墓碑 id，避开 `taskId` 唯一索引），
并先取消旧 Alarm 再排新的，避免两条提醒同时响。

## 4. 无障碍与细节

- 底栏三个 Tab 从 `clickable` 换成 `selectable(role = Role.Tab)`，TalkBack 会读「已选中」。
- 底栏高度收进 `Sizes.bottomBar`，FAB 的 66dp 偏移改成 `Sizes.bottomBar + Space.xs` 推导。
- 概览卡与统计指标启用 `tnum`，数字变化时不再左右抖。
- 筛到空分类时给「看全部任务」，不用退出去重选。
- 新增 `Motion` 令牌（80 / 140 / 220 / 320ms + 两条曲线 + 两条弹簧），新代码不再散写 `tween(180)`。

## 5. 没做的

- **不做整屏换色 / 动态取色（Material You）**：会打破纸面的一致性，也要重算全套对比度；
  真要动态色，应该连纸面一起做，那是另一轮。
- **不做拖拽排序**：现有上移 / 下移 + 四种排序已经覆盖；拖拽要处理滚动冲突与长列表性能。
- **主题色不进备份 / 同步**：属于本机外观偏好，换设备重新选一次比合并冲突便宜。
- **专注页不跟随主题色**：那一页是沉浸式渐变 + 衬线引语，彩色按钮会破坏它。
