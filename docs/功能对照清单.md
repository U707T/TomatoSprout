## 已知偏离与原因

1. **模块划分**：合并为 `:app` + `:core:domain`。提示词明确允许小团队先合并，Domain 仍保持无 Android 依赖。
2. **提醒精度**：不申请 `SCHEDULE_EXACT_ALARM`，允许系统推迟几分钟；已申请 `RECEIVE_BOOT_COMPLETED`，由 BootReceiver 在开机 / 应用更新后重排本地提醒。
3. **实时活动**：不使用前台服务；进程被杀后通知会停在最后状态，直到回到 App 结算。若 ROM 不展示 Heads-Up，则表现为普通通知。
4. **测试**：Domain 使用 JUnit 5（39 个用例）；`app` 层沿用 JUnit 4（哈希单测）。Room 已到 v4，`MIGRATION_1_2`（子任务/排序/计时字段）、`MIGRATION_2_3`（结算结果/归属日期）、`MIGRATION_3_4`（实际番茄数回填）均无 DROP TABLE；迁移 SQL 已做 SQLite 执行验证，设备级 Room MigrationTest 可在后续加入。
5. **独立页面**：连续纪录、目标进度合并进“回顾 / 任务”视图；核心数据均已计算与展示。
6. **CSV 导入**：未实现，仅支持 JSON 全量导入（导出仍提供 CSV 便于表格查看）。
