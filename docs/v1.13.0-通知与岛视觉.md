# v1.13.0 — 超级岛 / 实时通知的视觉重做

## 一、问题

v1.12.0 把通道走通之后，功能是好的，但看起来寒酸：

- 岛上只有一枚白色小 glyph（`ic_notification` 是状态栏用的单色矢量），放在彩色岛里像块白点；
- 通知卡片只有「标题 + 一行正文」，没有大图标、没有强调色、没有进度；
- `baseInfo` 只用了官方的两个文本槽（title / content），另外两个（subTitle / subContent）空着；
- 大岛 A 区把「状态」放在第一行、「任务名」放第二行 —— 4 个汉字宽的位置，最该露脸的任务名被挤到次行。

## 二、参考了什么

| 来源 | 拿到的结论 |
|---|---|
| [HyperIsland-ToolKit](https://github.com/D4vidDf/HyperIsland-ToolKit)（Kotlin 库，23+ 官方模板） | `BaseInfo` 有四个文本槽 + 每槽的浅色/深色配色；小岛圆环是 `combinePicInfo{picInfo, progressInfo{progress,colorReach,colorUnReach,isCCW}}`；大岛倒计时是 `imageTextInfoLeft + sameWidthDigitInfo{timerInfo}`（与本项目结构一致） |
| ScheduleTimeline 真机调查（Xiaomi 17 / HyperOS 3.0.317） | 岛依附 **IMPORTANCE_HIGH** 渠道；胶囊在剩余 ≤2 小时时交给系统实时倒计时、超过 2 小时会因标题过长撑破胶囊；大岛 A 区约 4 个汉字宽 |
| Live Clock 2.3.0（v1.12.0 的通道参考） | 实时更新只需要 `android.requestPromotedOngoing` + `android.shortCriticalText`，样式回到标准/进度样式 |

## 三、改了什么

### 3.1 图标

- 新增 `drawable-nodpi/ic_island.png`：把 `design/icon/icon_circle_1024.png`（纸雕番茄芽）缩到 256px，65 KB（小米图片限制 100 KB 内）；
- 状态栏仍用单色 `ic_notification`（系统要求），**卡片大图标与岛内图片**改用彩色版本。

### 3.2 通知卡片

| 位置 | 之前 | 现在 |
|---|---|---|
| 大图标 | 无 | 彩色番茄芽（`setLargeIcon`） |
| 强调色 | 无 | `setColor(番茄红/休息绿/完成深绿)`，染色小图标、应用名与进度条 |
| 标题 | `专注中 · 写周报` | `写周报`（任务名优先） |
| 副标题 | — | `专注中` / `休息中` / `已暂停`（`setSubText`） |
| 正文 | `15:24 结束` | `剩余 14:59 · 15:24 结束`（暂停/正计时/完成各有对应文案） |
| 进度 | 无 | 实时更新档位用 `ProgressStyle`（单段、强调色、按已专注百分比）；普通卡片档位用原生 `setProgress` |

### 3.3 超级岛（OS3 厂商参数）

- `baseInfo` 从两行扩到四行：`title`=任务名、`subTitle`=状态、`content`=剩余/已专注、`subContent`=时长，并补齐 `colorTitle/colorSubTitle/colorContent/colorSubContent` 与其深色变体；
- 大岛 A 区顺序对调：**第一行任务名、第二行状态**（4 个汉字宽，先把最重要的露出来）；
- 完成帧沿用 `dismissIsland=true` 与深绿强调色；小岛继续用彩色图标 + 进度环。

### 3.4 状态栏胶囊

- 倒计时剩余 **≤ 2 小时**：不写 `shortCriticalText`，让系统按 `setWhen + chronometer` 在胶囊里走实时倒计时（比 10 秒刷新一次的静态文字直观）；
- 超过 2 小时（最长 3 小时）：退回紧凑文案 `剩 180 分`，避免系统显示完整标题把胶囊撑破；
- 暂停 / 正计时 / 完成：静态文案 `已暂停` / `已专注 05:32` / `已完成`。

## 四、没有破坏的东西

- 实时更新的硬性条件照旧满足：`POST_PROMOTED_NOTIFICATIONS`、`ongoing`、有 `contentTitle`、**无自定义 RemoteViews**（自绘卡片只在普通卡片档位用）、非分组摘要、频道 `IMPORTANCE_HIGH`；
- 所有档位仍互斥，不叠加；
- 岛的按钮仍是广播，点按不跳 App；
- 没有新增权限、没有引入前台服务、没有第三方库依赖（参考库只用来核对字段与配色，不引入）。

## 五、验证

```bash
./gradlew :core:domain:test :app:testDebugUnitTest   # domain 54 / app 21
./gradlew :app:lintDebug                             # 0 error
./gradlew :app:assembleDebug                         # 通过
```

真机看三处：

1. 通知栏卡片：左侧彩色番茄芽、番茄红强调色、标题是任务名、下面有进度条；
2. 状态栏胶囊：剩余 2 小时内应是一个自己在走的倒计时；
3. 展开岛（OS3/白名单设备）：A 区第一行任务名、第二行状态；B 区大号倒计时 + 「剩余」；小岛是彩色图标 + 进度环。
