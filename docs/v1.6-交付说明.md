## 首页入口规则（v1.6.1）

| 任务计时方式 | 首页卡片按钮 | 打卡来源 |
|---|---|---|
| 不计时（按次） | `打卡` / `继续打卡` / `已打卡` | 首页直接写入 CheckIn |
| 倒计时 / 正向计时 | 仅 `开始` → 专注页 | 专注完成后自动写入 CheckIn |

计时的习惯 / 待办 / 目标不再显示手动打卡按钮，避免「没专注也能打卡」的二义性；需要按次打卡时，把任务的计时方式改为「不计时」。

## 专注结算矩阵

| 结束方式 | FocusSession | CheckIn | 备注 |
|---|---|---|---|
| 倒计时自然结束 | ✅ `outcome=completed` | ✅ 自动写入 | 同时刷新徽章与连续天数 |
| 正计时 ≥30s 且确认记录 | ✅ `completed` | ✅ | 结束后弹窗确认 |
| 正计时 <30s，忽略开关开启 | ❌ 丢弃 | ❌ | 不写任何记录 |
| 正计时 <30s，忽略开关关闭 | 用户确认后 ✅ | 用户确认后 ✅ | 不确认则丢弃 |
| 手动停止（未达计划时长） | ✅ `outcome=interrupted` | ❌ | 严格模式下彻底丢弃 |
| 手动停止（已达计划时长） | ✅ `completed` | ✅ | 按自然完成处理 |
| 休息计时 | ❌ | ❌ | 只显示休息结束摘要 |

跨午夜：默认 `attributedDate = 结束日`；开启「午夜模式」后 `attributedDate = 开始日`。`isMidnightShifted` 仅表示是否真的跨天。

## 删除任务与孤儿数据

- v1.6 取消 `TaskStatus.ARCHIVED`；删除只使用 `Task.deletedAt` 软删除。
- 删除任务时：删除提醒、习惯/目标规则、子任务；**不删除** `CheckIn` / `FocusSession`。
- 历史页与统计图表通过 `TaskDisplay.title(task)` 统一输出：
  - 任务存在 → 原名；
  - 任务软删除 → `[已删除] 原名`；
  - 任务行缺失 → `[已删除] 原任务`。
- 历史卡片对已删除任务置灰、不可点击编辑；统计环形图仍计入时长，只是图例置灰。

## Room v2 → v3 Migration

`AppDatabase.MIGRATION_2_3`（无 DROP TABLE）：

1. `tasks`：`status='ARCHIVED'` → `status='TODO'`，`deletedAt = MAX(updatedAt, 1)`（保留用户“隐藏任务”的意图）。
2. `focus_sessions` 增加 `outcome TEXT`、`attributedDate TEXT`、`checkInId TEXT`（全部可空）。
3. 旧专注回填 `outcome='completed'`；`attributedDate` 用 `strftime('%Y-%m-%d', endedAt/1000, 'unixepoch', 'localtime')` 回填。

迁移 SQL 已用 SQLite 逐步执行验证：任务状态/删除时间、专注回填结果与 `PRAGMA table_info` 均与导出的 `app/schemas/.../3.json` 对齐。

## 统计页防闪退

- `StatsCalculator` 与 `StatsViewModel` 双重过滤 `actualSeconds < 0`、`endedAt <= 0`。
- `DonutChart`：`slices.isEmpty() || totalSeconds <= 0` 时 Canvas 直接 `return@Canvas`，外层显示「暂无专注数据」。
- `MonthlyBarChart`：`bars.isEmpty()` 时 Canvas 直接返回；`maxVal = maxOfOrNull { seconds }?.coerceAtLeast(1) ?: 1`；`slot <= 0` 时停止绘制。
- 所有查询 Flow 使用 `stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), initial)`。
- 所有集合渲染使用 `items(key=...)` / `key(...)`。

## 红线复查

- 无「学霸模式 / 白名单 / 应用拦截 / UsageStatsManager」代码或文案。
