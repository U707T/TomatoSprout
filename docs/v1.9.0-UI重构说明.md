# v1.9.0 UI 重构说明

这轮重构的目标不是「换一套颜色」，而是把信息层级、点击路径和视觉语言一起收口：
**暖白纸感 + 番茄红点缀，层级靠排版和留白，不靠彩色块堆叠。**

## 1. 设计系统

新增/重写：

| 文件 | 内容 |
|---|---|
| `ui/theme/Tokens.kt` | 色板、间距（4→40dp）、圆角（8→30dp）、触控尺寸 |
| `ui/theme/Type.kt` | 15 级排版；计时数字使用等宽 `tnum` 字形 |
| `ui/theme/Theme.kt` | 浅色/深色 ColorScheme、Shapes、状态栏图标明暗 |
| `ui/components/Paper.kt` | 大标题、返回栏、分段控件、胶囊、指标、细进度条、设置行/分组、底部弹层、插画空状态、触感、撤销 Snackbar |
| `ui/components/Components.kt` | 重写卡片/空状态/圆环/热力图/确认弹窗，保持旧 API 兼容 |

关键令牌：

- 背景 `#FAF6F1`（暖纸），卡片 `#FFFFFF`，描边 `#EBE1D7`
- 主色 `#E0553F`，浅容器 `#FCE7E0`；辅助色 `#7C9A6F`、`#E2A05C`、`#6E8AA8`
- 深色模式背景 `#14110F`，不是纯黑
- 卡片统一 1dp 描边 + 0dp 阴影；只有浮层用阴影

## 2. 页面改动

1. **首页（任务）**
   - 顶栏改成「问候 + 日期 + 一句话进度」，历史入口只保留一个
   - 新增今日概览卡：番茄数 / 专注分钟 / 完成比 + 完成率圆环，点击进统计
   - 新增分类筛选：全部 / 习惯 / 待办 / 目标 / 番茄，带数量
   - 彩色渐变大卡改成白底任务卡：图标底色、标题、元信息、细进度条、圆形动作按钮
   - 动作语义按类型收敛：计时任务「开始」、按次任务「打卡/加一次」、完成态「重新打开」
2. **新建任务**
   - 保留窗口形态，重做为纸感居中窗口：固定标题栏（含关闭按钮）与底部按钮，中间内容可滚动
   - 键盘弹出时窗口整体上移并限制在可视区域内；小屏 / 大字体不会把「创建」顶出屏幕
   - 类型 / 计时方式改成两段式选择；时长用 5 分钟步进，不再需要记范围
   - 「更多设置」直达完整编辑页
3. **统计**
   - 新增今日 Hero 卡（专注分钟 + 30 天完成率圆环 + 连续/累计/番茄）
   - 周节奏、分布、月度、时段、打断、纪录、热力图统一为「一卡一件事」
   - 热力图/区间的 FilterChip 改成 SegmentedTabs
   - 历史与徽章入口改成设置行，不再用 emoji 卡片
4. **底栏**
   - 改为「任务 / 专注 / 统计 / 我的」，中间「专注」是动作入口，补上此前只能从通知进入的自由专注
5. **我的（设置）**
   - 改成分组设置：外观 / 专注 / 提醒 / 数据 / 更多
   - 主题改成三选一分段控件
   - 数字项改成「标签 + 当前值 + −/+」，删除/清除类操作使用错误色
6. **专注页（v1.9.1 按参考图重做）**
   - 全屏柔和渐变背景（本地生成）+ 衬线斜体引语，信息从「控件」改成「排版」
   - 中间只保留超大计时字 / 「开始」、番茄序号与进行中状态
   - 底部 5 个线性图标：亮度 / 声音 / 开始暂停 / 重置 / 停止；声音与亮度按需展开
   - 移除刻度圆环、音频胶囊、常驻亮度滑杆与 80dp 实心按钮
   - 结算/停止/记录弹窗统一为暖炭灰深色，避免在沉浸页闪出浅色弹窗
7. **历史**
   - 返回栏统一；月历卡片改为描边卡
   - 时间轴记录从「彩色底」改为白底 + 左侧色条
   - 写心得改成底部弹层
8. **编辑页**
   - 类型 / 计时 / 优先级 / 频率从 FilterChip 改为分段或胶囊
   - 表单间距统一到 8pt 栅格
9. **徽章 / 愿望 / 关于 / WebDAV / 同步日志**
   - 统一 `BackBar`、卡片描边、指标与按钮层级
   - 愿望清单改用可点击圆环完成，添加入口内联
   - WebDAV 保存改主按钮，测试连接改次按钮

## 3. 操作逻辑

| 原来 | 现在 |
|---|---|
| 删除任务要连续两次确认 | 一次确认，说明保留历史 |
| 撤销打卡弹确认框 | 单次打卡直接撤销 + Snackbar「撤销」；多次打卡仍二次确认 |
| 打卡无触感 | 打卡/删除/切换有 `HapticFeedback` |
| 首页无法筛选 | 5 类筛选，带计数 |
| 新建要滚一屏选项 | 居中窗口，输入即聚焦，回车可创建 |
| 「打卡卡片简约模式」设置无效 | 首页卡片按设置隐藏进度与次要元信息 |
| 专注页切声音要展开菜单 | 胶囊一键切换 |
| 设置项平铺 | 分组 + 数值步进 + 危险操作着色 |
