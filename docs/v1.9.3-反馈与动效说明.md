# v1.9.3 · 触感、音效与动效

## 为什么之前“一点反馈都没有”

v1.9.1 的触感走的是：

```kotlin
view.performHapticFeedback(HapticFeedbackConstants.CLOCK_TICK)
```

`CLOCK_TICK` 在不少国产 ROM 上会返回成功但实际不振动；而且只在首页打卡、删除、专注几个按钮上调用，底栏、筛选、分段、设置项都没有接。音效则完全没有实现。

## 现在的反馈层

### 触感

`ui/feedback/Feedback.kt` 统一封装：

| 场景 | 振动 |
|---|---|
| 普通点击 / 切换 | 16ms、振幅 120 |
| 成功：打卡 / 创建 / 完成 | 16ms + 45ms 间隔 + 22ms，振幅 140 / 190 |
| 失败 / 删除 / 拒绝 | 22ms + 55ms 间隔 + 26ms，振幅 170 / 215 |

- 直接用 `Vibrator` / `VibratorManager`，不再依赖 View 的 haptic 常量。
- 不支持振幅控制的设备自动退化为固定时长波形。
- `VIBRATE` 是普通权限，没有运行时弹窗；App 内「我的 → 反馈 → 触感反馈」可关闭，默认开启。

### 音效

3 个本地合成音效（非第三方素材，`res/raw`）：

| 文件 | 时长 | 用途 | 音量 |
|---|---|---|---|
| `ui_tap.ogg` | 55ms | 点击 / 切换 | 0.30 |
| `ui_done.ogg` | 640ms | 打卡 / 创建 / 完成 | 0.45 |
| `ui_error.ogg` | 300ms | 删除 / 错误 / 拒绝 | 0.40 |

- `SoundPool` + `USAGE_MEDIA`，低延迟，跟随媒体音量。
- 设置「我的 → 反馈 → 操作音效」可关闭，默认开启。
- 不在音频焦点上抢占音乐；只是很短的提示音。

### 接入范围

首页：打卡 / 撤销 / 新建 / 删除 / 筛选 / 卡片点击与长按 / FAB。
专注：开始 / 暂停 / 重置 / 停止 / 声音 / 亮度 / 任务选择 / 时长步进 / 结算。
底栏：四个入口。
其余：设置开关与步进、愿望清单、历史日期与补卡、编辑页保存与删除、WebDAV 保存/测试/同步、同步日志清空、返回栏。

## 动效

| 位置 | 动效 |
|---|---|
| 进度条 | 420ms 补间，不再瞬移 |
| 勾选圆点 | 0.88 → 1.0 弹簧缩放 + 颜色过渡 |
| 任务动作按钮 | 加号 / 播放 / 勾选交叉淡入 |
| 任务卡 | `animateContentSize`，进度行出现/消失不跳变 |
| 首页列表 | `animateItem()`，筛选与排序时位移/淡入淡出 |
| 分段控件 / 筛选胶囊 | 选中缩放 + 颜色过渡 |
| 底栏 | 选中图标 1.08 倍弹簧缩放 |
| FAB | 按下 0.94 倍 |
| 新建窗口 | 0.94 → 1.0 弹簧缩放 + 淡入 |
| 二级页 | 200ms 淡入 + 1/14 屏滑入；返回反向 |
| 专注页 | 背景 900ms 缓入缩放；图标按下 0.86 倍 |
| 徽章 | 解锁缩放淡入（原有） |

## 权限变化

Manifest 新增：

```xml
<uses-permission android:name="android.permission.VIBRATE" />
```

- 普通权限，安装即授予，不会弹窗。
- 只用于触感反馈；关闭 App 内开关后完全不调用 Vibrator。
- README 权限表已从 4 项更新为 5 项。
