# v1.9.2 · 未完成专注的结算与退出

## 问题

v1.9.1 的专注页在结算后一律弹出 `SessionSummaryDialog` 并停留：

- 倒计时 25 分钟，做到 5 分钟手动停止 → 弹「已记录中断」摘要，页面还在计时页；
- 正计时 10 秒停止 → 弹「不足 30 秒」摘要，页面还在计时页；
- 严格模式提前结束 → 弹「作废」摘要，页面还在计时页。

用户想回到任务页，必须再点一次关闭 + 返回，路径是「停止 → 确认 → 关闭摘要 → 返回」四步。而且不足 30 秒的规则只对正计时生效，倒计时 3 秒停止还会写一条 3 秒的中断记录。

## 决策

结算结果分四类，页面行为不同：

| 结算结果 | 是否写记录 | 是否打卡 | 页面行为 |
|---|---|---|---|
| 倒计时自然结束 | 写 completed | 是 | 留在专注页看摘要，可开始休息 / 再来一个 |
| 正计时确认记录 | 写 completed | 是 | 留在专注页看摘要 |
| 手动停止（≥30 秒） | 写 interrupted | 否 | **Toast「已记录中断 N 分钟」→ 直接回任务页** |
| 放弃 / 严格模式 / 不足 30 秒 | 不写或仅 discarded | 否 | **Toast 说明原因 → 直接回任务页** |
| 休息结束 / 停止休息 | 不写专注 | 否 | 留在专注页看休息摘要 |

## 实现

- `FocusTimerViewModel` 新增 `exit: SharedFlow<FocusExit>`；`handleSummary()` 只在「完成 / 休息」时把摘要写进 UI 状态，其余情况发退出事件。
- `FocusTimerScreen` 收集退出事件：`Toast` 说明原因后调用 `onExit()`。
- `FocusSessionUseCase` 的 30 秒忽略规则从 `COUNTUP_FINISHED` 扩展到 `MANUAL_STOP`：
  - 正计时 <30 秒且忽略 → 丢弃；
  - 倒计时 <30 秒手动停止且忽略 → 丢弃，不写 3 秒的中断记录。
- `requestStop()` 对倒计时 <30 秒且开启忽略的情况，不再弹停止确认，直接结算并退出。
- 设置项文案改为「忽略 30 秒内的专注」。

## 同类路径审计

| 路径 | 原行为 | 现在 |
|---|---|---|
| 计时中重置 | 直接清空，无确认，记录丢失 | 有进度时先确认「放弃并重置」 |
| 已完成任务出现在专注选择器 | 可以给已完成任务继续加番茄 | 选择器过滤 DONE；`startFocus` 防御校验 |
| 专注中任务被删除 / 改名 | 结算时按当前任务取，可能变成「自由专注」且丢失归属 | 开始专注时快照任务 id / 标题；已删除任务仍跳过打卡 |
| 不足 30 秒的倒计时停止 | 写中断记录 | 按设置丢弃，不写记录 |
| 停止确认后 | 留在计时页 | 自动回任务页 |
