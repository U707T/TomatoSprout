# v1.15.0 交互收敛说明

这轮不加新功能，只解决「用久了会踩到的坑」。按风险排序：**先保住数据，再补可见性，最后统一视觉**。

底栏保持 **任务 / 统计 / 我的** 三个位置不变。

---

## 1. 数据安全

### 1.1 编辑页返回不再静默丢弃

之前 `BackBar(onBack = onBack)` 直接 pop，保存只挂在按钮上；改了五个字段误触返回就全丢。

现在：

- `HabitEditViewModel` 在 `load()` 结束时存一份 `baseline`，`isDirty()` 比较去掉 `loading/saving/error` 与子任务后的快照；
- 返回（顶部返回键、系统返回键）统一走 `attemptBack()`：脏了就弹「保存 / 放弃修改 / 取消」；
- 已存在任务的子任务是即时写库的，所以比较时排除，避免「只是加了个子任务」也被判为未保存。

### 1.2 保存失败一定看得见

错误原本只渲染在表单末尾，而顶栏也有一个「保存」。在页面顶部点击时，错误在几百 dp 之外，表现为「点了没反应」。

现在 `state.error` 变化时同时弹 Snackbar，内联错误保留在原位。

## 2. 专注页语义

- 计时中按系统返回键或顶部返回，弹「专注还在进行」：**结束并结算 / 留在后台 / 继续专注**。
- 「留在后台」保持原来的行为：页面关闭，计时快照仍在，通知可点回。
- 顶部按钮的 `contentDescription` 从「退出专注」改为「收起专注」——它从来不会结束计时。
- 未开始计时时返回仍然直接退出，不打扰。

## 3. 撤销条（替代 Snackbar 撤销）

原实现用 `SnackbarHostState.showUndo`，问题有两个：

1. 后台结算消息、创建成功消息会顶掉撤销条，`showUndo` 返回 `Dismissed`，删除立即落地；
2. 撤销打卡是 toggle，10 秒内又打卡会让「恢复」变成再撤一次。

现在：

| 组件 | 职责 |
|---|---|
| `UndoBar` | 删除 / 撤销打卡的 10 秒窗口，带线性倒计时；与 Snackbar 分开渲染，互不顶替 |
| `Snackbar` | 只承载普通消息（创建成功、结算摘要、错误） |
| `CheckInUseCase.undoToday()` | 精确撤销今天的打卡，不再 toggle |

删除统一为「先隐藏卡片 → 10 秒撤销窗口 → 超时才写库」；左滑与长按菜单共用这一条路径，首页不再弹删除确认框。编辑页内的删除仍保留确认框（那里无法显示首页撤销条）。

## 4. 可见性

### 4.1 排序依据

上一版加了「按优先级 / 截止时间排序」，但卡片上看不到这两个字段，排序结果看起来是随机的。现在：

- 优先级为「紧急且重要」时，标题前一个 6dp 红点（带无障碍描述）；
- 截止时间显示在 meta 行右侧：`今天到期 / 明天到期 / 周三到期 / 逾期 N 天`，逾期用错误色；
- 截止时间由编辑页统一写成 23:59，所以只显示日期粒度。

### 4.2 自由专注入口

底栏不变的前提下，入口放在今日概览卡底部：`自由专注 · 25 分钟` + 「开始」，分钟数取设置里的默认专注时长，正计时/倒计时跟随默认设置。

### 4.3 隐藏已完成与搜索

- 「隐藏已完成」放在排序弹层（与「简约卡片」同层），存 DataStore；全部做完时首页给「显示已完成」。
- 搜索按标题与备注过滤，入口在右上角放大镜；空结果给「清除搜索」。

## 5. 视觉收敛

| 问题 | 处理 |
|---|---|
| 空状态是 emoji 圆底，和首页插画两套语言 | `EmptyState` 改为矢量图标；统计 `DateRange`、徽章 `Star`、愿望 `FavoriteBorder`、同步日志 `List` |
| 统计翻页用文字 `‹ ›` | 换成 `IconButton` + AutoMirrored 箭头，补「前一天 / 后一天」描述 |
| 颜色选择的勾固定白色，亮黄底几乎看不见 | 抽出 `Color.readableContentColor()`，按亮度选深/浅前景，首页动作按钮与编辑页色板共用 |
| 首页错误态是一行裸文字 | 改为 `EmptyState` + 「重试」 |
| 历史首屏没有加载反馈 | 加载中在日历上方显示 2dp 进度条 |
| 动效时长散落 | 新代码统一用 `Motion`；旧代码暂未全量替换（见下） |

## 6. 结构

- `TodoScreen.kt`：1045 → 969 行；
- `TaskCard.kt`：卡片、滑动外壳、露出层；
- `UndoBar.kt`：撤销条状态与组件；
- `TodoDerived.kt`：`dueInfo()`、`filterCards()` 纯函数；
- 新增 `TodoDerivedTest`（5 个用例）：逾期天数、今明、周内、远日期、筛选与隐藏已完成。

## 7. 这轮没做

- **拖拽排序**：上移/下移 + 四种排序已覆盖，拖拽要处理滚动冲突；
- **动效与间距全量替换**：仍有许多 10/18/22dp 与非令牌时长，视觉收益低、回归面大，留到专门的一轮；
- **平板宽度约束**：主列表在宽屏仍会拉满；
- **提醒模型扩展**：snooze / 截止前提醒仍只有「每天固定时间」。
