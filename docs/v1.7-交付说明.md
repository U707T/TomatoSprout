# 番茄芽 v1.7 交付说明

对齐对象：番茄ToDo（上海盼推科技）公开产品链路 ——
「待办清单（子任务 / 预估番茄）→ 番茄钟专注 → 完成计入实际番茄 → 休息 → 打卡与统计」，
官方功能口径见 <https://www.tomatodo.cn> 与 App Store 产品页。

本项目仍遵守既有红线：**不做学霸模式 / 白名单 / 应用拦截 / UsageStats / 自习室 / 社交排名**，
只对齐「本地、可解释、不索权」的那部分链路。

## 1. 番茄ToDo 链路对照

| 番茄ToDo 能力 | 番茄芽 v1.7 | 说明 |
|---|---|---|
| 待办清单 + 子任务 | ✅ | `tasks` + `subtasks`，父任务由子任务完成度汇总 |
| 预估番茄 / 实际番茄 | ✅ | 编辑页可设 0–99 个预估；倒计时完成自动 +1；v4 迁移按历史专注回填 |
| 倒计时 / 正计时 | ✅ | 倒计时按计划时长结算；正计时结束后确认记录 |
| 短休息 | ✅ | 完成后一键「开始休息 N 分钟」 |
| 每 4 个番茄长休息 | 🟡 | 未自动建议长休息，休息时长仍由设置统一控制 |
| 打断原因 | 🟡 | 只记录 `interruptionCount`，未采集文字原因（后续可加轻量枚举） |
| 高效时间区间 | ✅ | 24 小时柱状；v1.7 起跟随当前区间与任务筛选 |
| 专注时长分布 / 热力图 / 周月完成率 | ✅ | 环形分布、月柱状、月/年热力图 |
| 成就徽章 | ✅ | 连续 / 打卡 / 时长 / 番茄 / 圆满日 |
| 到点提醒 | 🟡 | AlarmManager 非精确；BootReceiver 开机重排，不做「不完成就反复提醒」 |
| 学霸模式 / 白名单 / 锁机 | 🚫 | 永久禁止清单，不申请相关权限 |
| 自习室 / 好友排名 | 🚫 | 无账号、无后端、无社交 |

## 2. 数据口径（v1.7 统一）

| 指标 | 定义 |
|---|---|
| 实际番茄数 `Task.completedPomos` | 该任务下 `mode='pomodoro'` 且 `outcome='completed'` 的专注条数 |
| 专注时长 | 所有 `completed` 专注的 `actualSeconds` 之和（正计时也算时长） |
| 打卡 CheckIn | 倒计时/正计时「完成」时自动写入；中断、严格模式作废不写 |
| 连续天数 | 基于 CheckIn 与习惯排期计算；非排期日不写打卡 |
| 归属日期 | 默认结束日；开启「午夜模式」取开始日；落库到 `attributedDate` |

`MIGRATION_3_4` 回填 SQL：

```sql
UPDATE tasks
SET completedPomos = (
    SELECT COUNT(*) FROM focus_sessions f
    WHERE f.taskId = tasks.id
      AND f.deletedAt IS NULL
      AND f.mode = 'pomodoro'
      AND COALESCE(f.outcome, 'completed') = 'completed'
)
```

## 3. 本版修复的主链路问题

1. **倒计时恢复污染统计**：进程被杀数小时后回前台，`elapsedRealtime` 会把后台时间算进专注，
   现在 `FocusSessionUseCase` 对倒计时按 `plannedSeconds` 封顶，并把 `endedAt` 校正回
   「开始 + 实际时长」。
2. **结算写丢失**：结算从 `viewModelScope` 移到 `@ApplicationScope`，退出专注页也能落库。
3. **实际番茄数不涨**：原先只对 `TaskType.POMODORO` 累加，习惯/待办/目标永远 0；
   现在统一按番茄钟专注累加，并回填历史。
4. **预估番茄是死字段**：原先只能被数据库默认成 0，无编辑入口；现在编辑页可调。
5. **排序静默失效**：`sortOrder` 有重复值时上下移动交换的是同一组值；改为每次移动先归一化。
6. **幽灵打卡**：非排期日写 CheckIn 会显示「已打卡」但不计连续天数；现在直接拒绝并提示。
7. **统计口径打架**：「日均」用全时段数据、「高效时段」忽略筛选；现在全部走 `inRange`。
8. **首页 O(任务×记录)**：卡片计算前先按 taskId 分组一次。
