# v1.9.4 · 专注声音无缝循环与电平修复

## 问题

`FocusAudioPlayer` 用 `MediaPlayer.isLooping = true` 循环 raw 音频。但白噪音 / 棕色噪音素材是按「一次性播放」制作的：

- 开头 0.46s 淡入、结尾 0.5s 淡出；
- 每 8 秒循环一次，音量就被拉到 0 再升回来，听感是「一阵一阵」。

树叶风声更严重：整段电平只有约 **-52 dBFS**（其他环境音约 -25 ~ -35 dBFS），即使不循环也基本听不见。

v1.9.3 发布包里仍是原始素材；修复从 v1.9.4 开始生效。

## 处理

### 白 / 棕噪音

1. 用 20ms RMS 包络找到主体区间，裁掉头尾淡入淡出；
2. 首尾 0.25s **等功率交叉淡化**（`sin/cos` 权重，不是简单拼接），交叉段 RMS 恒定；
3. 输出 RMS 对齐原素材主体，峰值对齐原峰值，避免音量变化与削波；
4. 保持 22050Hz / 16bit / mono WAV，文件名不变。

| 文件 | 时长 | 50ms RMS 最低 / 中位 / 最高 | 接点样本差 vs 相邻 p99 |
|---|---|---|---|
| `white_noise.wav` | 8.00s → **6.85s** | 0.95 / 0.075 / 1.03 | 7168 vs 7685 |
| `brown_noise.wav` | 8.00s → **6.95s** | 0.72 / 0.182 / 1.44 | 1959 vs 2136 |

接点差小于噪音本身的相邻样本 p99，说明循环点没有爆音，只是正常噪声跳变。

### 树叶风声

- 原素材 13.84s，1.6s 渐强、10.6s 后渐弱，循环起来是 14 秒一次的呼吸；
- 裁掉头尾后做 **0.5s** 等功率交叉淡化；
- 电平从 -52 dBFS 提升到 RMS ≈ 0.032（与篝火 0.036 接近），峰值 0.245，不削波；
- 输出 **8.50s OGG**（54KB），资源名仍是 `R.raw.wind_leaf`。

## 代码

- 播放逻辑不变，仍是一个 `MediaPlayer` + `isLooping = true`。
- `FocusAudio.kt` 增加注释：循环素材不能带淡入淡出，避免以后换素材再次踩坑。
- 白 / 棕噪音仍是 WAV，风声从 MP3 改为 OGG；文件名 / 资源 ID 不变。
