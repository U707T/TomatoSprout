# 番茄芽 TomatoSprout 🍅

轻量打卡 + 番茄专注 + 数据回顾。原生 Android（Kotlin + Jetpack Compose），**不索权、不打扰、不空洞**。

当前版本 **v1.13.1**（targetSdk 36）。只申请 6 个权限：`POST_NOTIFICATIONS`（可选）、`POST_PROMOTED_NOTIFICATIONS`（普通权限，澎湃 OS 4 的岛走实时更新需要）、`INTERNET`、`ACCESS_NETWORK_STATE`、`RECEIVE_BOOT_COMPLETED`（重启恢复本地提醒）、`VIBRATE`（触感反馈，普通权限，无运行时弹窗）。

> 没有账号、没有托管后端、没有广告、没有埋点；没有使用情况监听、没有无障碍、没有悬浮窗、没有桌面小组件、没有前台服务常驻。

## 已实现

### 任务与打卡

- **四种任务**：习惯 / 待办 / 目标 / 番茄任务。
- **卡片流首页**：白底任务卡 + 细进度条，按完成状态、手动排序、优先级排列；标题前红点标「紧急且重要」，右侧显示「今天 / 明天 / 周三 / 逾期 N 天」。
- **四种排序**：手动 / 优先级 / 截止时间 / 今日专注，入口在首页右上「排序与视图」，选择会被记住。
- **搜索与隐藏**：右上放大镜按标题/备注过滤；排序弹层可「隐藏已完成」，全部做完时给一键恢复。
- **滑动操作**：卡片右滑打卡 / 完成 / 重新打开，左滑删除并给 10 秒撤销窗口；计时任务右滑不会误启动专注。
- **按次打卡**：不计时任务在首页直接点圆钮打卡；多目标习惯每次 +1，打满后显示完成。
- **计时任务**：卡片只显示「开始」，进入专注页完成一次专注后自动打卡。
- **撤销打卡**：单次打卡直接撤销并给 Snackbar「撤销」；多次打卡会先确认再全部撤销。
- **删除任务**：左滑或长按 → 删除，统一走「先隐藏 + 10 秒撤销条」，超时才真正软删除；打卡与专注历史保留，历史页显示「[已删除] 原任务名」并置灰。
- **编辑任务**：点卡片进入编辑页，可改名称、备注、图标、颜色、优先级、截止时间、计时方式、预估番茄、子任务、提醒；改过内容后返回会问「保存 / 放弃 / 取消」。
- **快捷面板**：长按卡片打开，支持编辑 / 历史 / 统计 / 上移 / 下移 / 删除 / 提醒 / 换色 / 标记完成；提醒直接在弹层里选时间，不再跳整页编辑。
- **子任务**：独立子任务表；全部完成自动完成父任务，任一取消自动回退。
- **习惯排期**：每天 / 工作日 / 每周几 / 自定义间隔；可设每周期目标次数。
- **目标**：起止日期 + 累计目标次数（留空表示不限）。
- **本地提醒**：单任务定时提醒，受全局免打扰时段约束；开机 / 应用更新后自动重排。

### 专注

- **三种模式**：倒计时 / 正计时 / 按次（不计时）。
- **5–180 分钟**，5 分钟步进；倒计时结束自动结算并打卡，正计时结束需确认是否记录。
- **入口**：任务卡「开始」/ 底栏「专注」自由专注 / 通知回到进行中的专注。
- **控制**：暂停 / 继续、重置、停止；严格模式下不可暂停，提前结束彻底作废。
- **中断原因**：停止时可选「分心了 / 被外界打断 / 主动放弃 / 其它」，写入专注记录。
- **短专注处理**：正计时 / 倒计时不足 30 秒时，可按设置直接丢弃，不留中断记录。
- **未完成即退出**：中途停止、放弃或不足 30 秒，结算后不停留在计时页；Toast 说明原因后直接回任务页。
- **长休息**：每完成第 4 / 8 / 12… 个番茄，结算摘要建议长休息（10–60 分钟可调）。
- **跨午夜**：默认归属结束日；开启「午夜模式」后强制归属开始日；每条专注保存 `attributedDate`。
- **后台校正**：基于单调时钟，回前台按真实流逝校正；进程被杀后从快照恢复。
- **专注页**：全屏渐变背景 + 衬线引语 + 超大计时字；底部亮度 / 声音 / 开始暂停 / 重置 / 停止 5 个线性图标。计时中返回会先问「结束并结算 / 留在后台 / 继续专注」。
- **环境辅助**：屏幕常亮、亮度调节、沉浸模式、6 种本地声音（白噪音 / 棕色噪音 / 树叶风声 / 篝火 / 钢琴 / 八音盒；白 / 棕噪音与风声为无缝循环）、分享海报。
- **系统实时活动**：专注把倒计时交给系统自己走秒 —— 澎湃 OS 4 走 **Android 16 实时更新**（系统的岛直接渲染这条通知），OS3 及更早走**焦点通知 / 超级岛**（小岛 + 大号倒计时 + 进度环 + 息屏文案 + 暂停/继续/结束/延长 5 分钟），Android 16+ 用 `Notification.ProgressStyle` 显示进度型通知并申请常驻提升，其余系统仍用自绘卡片；暂停 / 继续 / 结束在所有档位都能点。

### 回顾

- **首页今日概览**：今日番茄数、专注分钟、完成比 + 完成率圆环；卡片底部「自由专注」可直接开始一次不挂任务的专注，点击卡片其余位置进入统计。
- **统计页**：今日 Hero 卡、日 / 周 / 月环形分布、本周节奏、月度柱状图、高效时段（24 小时）、打断原因、连续 / 最长连续、累计打卡 / 专注、圆满日、近 30 天完成率。
- **热力图**：月 / 年视图，可切换「打卡次数 / 专注时长」；点击某天进入历史。
- **历史时间轴**：月历 + 选中日时间轴；白底记录卡 + 左侧色条；点击记录写心得；最近 7 天可补卡并标记 `isMakeup`。
- **成就徽章**：连续 7 / 30 / 100 天、累计打卡 100 次、专注 100 小时、50 个番茄、圆满一日；解锁有轻量缩放淡入。
- **愿望清单**：内联添加、勾选完成、删除；随备份与 WebDAV 同步。

### 数据与设置

- **JSON 全量备份**：任务、习惯 / 目标规则、子任务、提醒、打卡、专注、徽章、愿望、设置。
- **JSON 导入**：字段校验后再写入，冲突保留本地版本；v2–v6 旧备份可导入。
- **CSV 导出**：打卡记录，可用 Excel 查看。
- **WebDAV 手动双向同步**：按记录 `updatedAt` 合并、软删除墓碑传播、冲突保留副本、ETag + 内容哈希比对、仅 Wi-Fi、失败最多重试 3 次、同步日志。
- **主题**：跟随系统 / 浅色 / 深色；深色为暖炭灰（`#14110F`），不是纯黑。
- **主题色**：番茄 / 黛青 / 松烟 / 赭石 / 梅子 / 墨色 六套强调色，只换按钮、链接与进度条，纸面底色不变；取值按 WCAG AA 锁定（有单测）。
- **专注默认值**：专注 / 休息 / 长休息时长、默认严格模式、默认正计时、午夜模式、短专注处理。
- **提醒设置**：通知开关、实时活动 / 超级岛开关、系统实时活动状态（未开启可一键跳系统设置）、免打扰时段。
- **打卡卡片简约模式**：只保留标题、连续天数和完成状态。
- **清除所有数据**：一次确认、不可撤销，数据库清理在事务内完成。
- **隐私**：无账号、无广告、无埋点、无第三方统计；`allowBackup="false"`，卸载前需手动导出。
- **WebDAV 密码**：Android Keystore AES-GCM 加密，不写入数据库、日志或同步文件。

### 反馈与动效

- **触感反馈**：点击 / 完成 / 删除三种强度，直接用 `Vibrator`，不再依赖可能静默的 `performHapticFeedback`。
- **操作音效**：3 个本地合成短音效（点击 55ms / 完成 640ms / 错误 300ms），`SoundPool` 低延迟播放。
- **开关**：我的 → 反馈，触感与音效均可关闭；默认开启，仅影响本机。
- **动效**：进度条与勾选动画、任务动作交叉淡入、列表增删位移、分段 / 胶囊缩放、底栏选中缩放、FAB 按压、新建窗口缩放淡入、二级页滑入、专注页背景缓入。

### 外观与无障碍

- 暖白纸感设计系统：`#FAF6F1` 背景、`#E0553F` 番茄红、1dp 描边卡片、8pt 间距栅格、15 级排版。
- 系统字体缩放；计时数字等宽（`tnum`），大字号下限制在可读范围内。
- TalkBack 基础标签、48dp 点击区域、线性图标自绘（不引入 `material-icons-extended`）。

## 明确不做（范围外）

| 不做 | 原因 |
|---|---|
| 账号体系 / 托管后端 / 自动云同步 | 保持本地优先与隐私；只用用户自己的 WebDAV，且必须手动触发 |
| 社交 / 排行榜 / 自习室 / 组队 | 不打扰，不做比较与攀比 |
| 广告 / 埋点 / 推送运营 / 第三方统计 SDK | 不收集任何用户数据 |
| 桌面小组件 / 锁屏小组件 | 不常驻、不占用桌面；需要看数据时打开 App |
| 前台服务 / 悬浮窗 / 常驻通知 | 不在后台长期占用资源；实时活动只在专注进行中存在，计时靠快照恢复 |
| 使用情况访问 / 无障碍服务 / 自启动 / 电池白名单 / 设备管理器 | 不申请敏感权限 |
| 精确闹钟 `SCHEDULE_EXACT_ALARM` | 提醒允许延迟几分钟，换取不申请特殊权限 |
| 系统日历双向同步 | 不申请日历读写权限；截止时间只在本机 |
| 应用锁 / 手势密码 | 交给系统锁屏；App 内不再叠加一层锁 |
| 多语言 / 国际化 | 当前仅简体中文，文案集中在界面层 |
| 平板 / 折叠屏专属双栏布局 | 做响应式适配，但不维护第二套布局 |
| iOS / Web / 桌面 / Wear / 车机 | 只做 Android 手机端 |
| 任务协作 / 分享编辑 | 没有账号体系，避免引入权限与冲突模型 |
| 皮肤商店 / 封面市场 | 固定设计语言 + 6 个内置声音，不维护素材商店 |

### 已知边界

- 提醒使用 `AlarmManager.setAndAllowWhileIdle`，可能延迟几分钟；不申请精确闹钟。
- 进程在计时中被系统杀死时，通知与岛上的秒数会按系统时钟继续走（`timerInfo` / chronometer），但结算要等回到 App；不申请前台服务常驻。
- 澎湃 OS 的超级岛 / 焦点通知是厂商私有模板，且有两道应用无法自己跨过的闸门：系统里本应用的「焦点通知」开关，以及澎湃 OS 4 起的云端白名单（开平开通服务 + 证书指纹 + 场景审核）。任一没放开时岛不出现，但通知、计时、结算全部正常；「我的 → 提醒 → 系统实时活动」里有自检、判定原因与一键跳转。
- Android 16 的实时更新需要用户在系统里允许「提升通知」；未允许时同样退回自绘卡片。
- 补卡只支持最近 7 天，更早的缺卡不补。
- WebDAV 只在点击「立即同步」时联网；失败重试最多 3 次，不会后台定时同步。
- 删除任务是软删除：任务从首页移除，但打卡 / 专注历史永久保留。
- 卸载或清除数据前必须手动导出，Android 自动备份已关闭。

## 操作路径

### 底栏

四个位置：**任务 / 专注 / 统计 / 我的**。

- 任务、统计、我的 是常驻 Tab。
- 专注是动作入口：一键进入自由专注，不是常驻 Tab。
- 进入历史、编辑、专注、徽章、愿望、WebDAV 等二级页时，底栏自动隐藏。

### 新建任务

1. 任务页右下角「新建」。
2. 窗口自动聚焦输入框，写名称；回车可直接创建。
3. 选类型：番茄 / 习惯 / 待办 / 目标。
4. 选计时方式：倒计时 / 正计时 / 按次（不计时）。
5. 调专注时长（5 分钟步进；按次时隐藏）。
6. 点「创建」。
7. 需要图标、备注、优先级、排期、子任务、提醒 → 点「更多设置」进入完整编辑页。

> 习惯默认按天排期；目标默认 30 天；之后都可以在编辑页改。

### 编辑 / 排序 / 删除

- **编辑**：点任务卡片；或长按 → 快捷面板 → 编辑。
- **排序**：首页右上「排序与视图」→ 手动 / 优先级 / 截止时间 / 今日专注；手动顺序仍可用长按 → 上移 / 下移微调。
- **换色**：长按 → 换色（循环切换内置色板）。
- **标记完成**：长按 → 标记完成 / 重新打开，或卡片右滑。
- **删除**：左滑卡片，或长按 → 删除；首页统一走 10 秒撤销条，超时才写库。编辑页内删除仍会确认一次。
- **搜索**：右上放大镜，按标题与备注过滤；清除后回到当前筛选。
- **隐藏已完成**：右上「排序与视图」→ 隐藏已完成。
- **删除后**：历史与统计保留，历史页显示为 `[已删除] 原任务名`。

### 打卡与撤销

- **按次任务**：点卡片右侧圆钮 → 打卡；多目标习惯每点一次 +1，进度条显示 `2/3`。
- **撤销单次**：已打满再点圆钮 → 直接撤销，底部出现「撤销」。
- **撤销多次**：当天打过多次时，会先弹确认，再全部撤销。
- **计时任务**：点「开始」进入专注；完成一次专注后自动打卡，不在首页手动打。

### 专注

- **带任务专注**：任务卡「开始」。
- **自由专注**：底栏「专注」。
- **回到进行中**：点专注通知。
- **空闲态**：大字「开始」、`− 25 分钟 +`、任务选择、倒计时 / 正计时提示。
- **运行态**：暂停 / 继续、重置、停止；底部细进度条显示进度。
- **停止**：弹窗选中断原因；严格模式下提前结束彻底作废。
- **结算**：倒计时自然结束自动打卡；正计时结束确认是否记录；不足 30 秒按设置丢弃。未完成的专注结算后自动返回任务页。
- **休息**：结算摘要可直接开始短休息；每第 4 个番茄建议长休息。
- **专注页工具**：顶部返回 / 沉浸 / 常亮 / 分享；底部亮度 / 声音 / 开始暂停 / 重置 / 停止。
- **重置**：已有计时进度时先确认「放弃并重置」，避免误触丢掉记录。

### 历史 / 补卡 / 心得

入口（任选其一）：

- 任务页右上角日历图标。
- 统计页右上角日历图标。
- 我的 → 历史时间轴。
- 长按任务 → 历史。
- 月度柱状图 / 月热力图 → 点某一天。

页内操作：

- 月历选日期 → 下方时间轴。
- 点一条记录 → 底部弹层写心得（300 字以内）。
- 右上「今天」→ 回到今天。
- 「补卡」→ 选择最近 7 天缺卡的习惯。

### 统计 / 徽章

- 底栏「统计」进入。
- 点「今日 Hero 卡」→ 当天历史。
- 点月度柱状图 / 月热力图某天 → 当天历史。
- 页面底部 → 历史时间轴 / 成就徽章。

### 我的

- **外观**：主题（跟随系统 / 浅色 / 深色）、主题色（番茄 / 黛青 / 松烟 / 赭石 / 梅子 / 墨色）、打卡卡片简约模式。
- **专注**：专注时长、休息时长、长休息、短专注处理、默认严格模式、默认正计时、午夜模式。
- **提醒**：允许通知、实时活动 / 超级岛（可查看系统状态并跳转系统设置）、免打扰时段（可设起止时间）。
- **数据**：WebDAV 同步、导出 JSON、导出 CSV、导入备份、清除所有数据。
- **反馈**：触感反馈、操作音效（均默认开启，只影响本机）。
- **更多**：成就徽章、历史时间轴、愿望清单、关于番茄芽。

### 数据 / WebDAV

- **导出 JSON**：我的 → 数据 → 导出 JSON 备份 → 选择保存位置（SAF，不申请存储权限）。
- **导出 CSV**：我的 → 数据 → 导出 CSV。
- **导入**：我的 → 数据 → 导入备份 → 选文件；字段校验通过才写入。
- **WebDAV**：
  1. 我的 → 数据 → WebDAV 同步。
  2. 填服务器地址、用户名、密码、远程目录。
  3. 「保存」→「测试连接」→「立即同步」。
  4. 右上「日志」查看条目数、冲突数与失败原因。
- **清除数据**：我的 → 数据 → 清除所有数据；建议先导出 JSON。

## 权限

| 权限 | 用途 | 可拒绝 |
|---|---|---|
| `POST_NOTIFICATIONS` | 习惯提醒 / 专注实时活动与通知卡片 | 是，静默降级 |
| `POST_PROMOTED_NOTIFICATIONS` | 专注时把通知提升为「实时更新」（澎湃 OS 4 的岛按这条渲染） | 系统设置里可关，关掉只剩普通通知 |
| `INTERNET` | 仅手动 WebDAV 同步 | — |
| `ACCESS_NETWORK_STATE` | 仅 Wi-Fi 同步判断 | — |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复本地提醒闹钟 | — |
| `VIBRATE` | 打卡 / 完成 / 删除的触感反馈 | 可在 App 内关闭 |

WorkManager 传递引入的 `WAKE_LOCK` / `FOREGROUND_SERVICE` 已在 Manifest 中显式移除；文件导出 / 导入使用 SAF，不申请存储权限。

## 设计取舍

- **提醒**：用 `AlarmManager.setAndAllowWhileIdle`，不申请 `SCHEDULE_EXACT_ALARM`，因此可能延迟几分钟；已申请 `RECEIVE_BOOT_COMPLETED`，开机 / 应用更新后由 BootReceiver 重排。
- **计时**：基于 `SystemClock.elapsedRealtime()` 的单调时钟；回前台按真实流逝校正，进程被杀后从 DataStore / SharedPreferences 快照恢复。不申请前台服务常驻。
- **实时活动**：三种呈现互斥（澎湃 OS 超级岛 / Android 16 进度型通知 / 自绘卡片），按机型能力挑一条。超级岛与 chronometer 都只下发「结束时刻 + 当前时刻」，秒数由 SystemUI 自己走，因此不需要每秒重发通知；内容指纹节流后跨进程调用比 v1.9 少 60%～90%。
- **通知按钮**：统一用 Activity PendingIntent，规避 Android 12+ 的通知 trampoline 限制；通知本身的标准按钮是所有 ROM 上的兜底入口。
- **WebDAV**：只支持用户自填服务器，无任何托管后端 SDK；未配置时零网络请求。同步按 `updatedAt` 双向合并，双方都改过时保留本地版本并把远端版本存为冲突副本。
